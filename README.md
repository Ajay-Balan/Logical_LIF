# Implementation of Logical Gates Using LIF Neurons  

This repository contains code and simulations for implementing AND, OR, NOT, and XOR gates using Leaky Integrate-and-Fire (LIF) neurons in Brian2.  

## Features  
- Single-neuron implementations for AND, OR, NOT.  
- Two-layer network for XOR.  
- Figures showing membrane potential dynamics.  

## Requirements  
- Python 3.8+  
- Brian2  
- Matplotlib
